# Support

Use GitHub Issues for DataSum support and discussion:

- bug reports
- installation problems
- confusing output
- statistical-method questions
- feature requests
- documentation suggestions
- teaching and research workflow ideas

Open an issue here: https://github.com/Uzairkhan11w/DataSum/issues

## Good issue reports

Helpful reports include:

- your R version and operating system
- the DataSum version
- a small reproducible example
- the exact error message or unexpected output
- what you expected to happen

## App questions

The Shiny app runs locally from R:

```r
run_datasum_app()
```

A hosted public web app is a separate deployment target and is listed on the roadmap.

## CRAN vs GitHub versions

CRAN may lag behind GitHub during active development. Check the README release-status note before reporting a missing function.

SUMMARY STATISTICS

Selected variable

iStatistics are calculated in this browser from non-missing values.
∑How these numbers are calculatedTransparent methods, no black boxes⌄

Empty CSV cells are treated as missing. Numeric columns are recognized when all non-empty values are finite numbers. Quantiles use R's type 7 definition; standard deviation uses the sample formula with n − 1 in the denominator.

QuartilesLinear interpolation at (n − 1)p
IQR outliersx < Q1 − 1.5 × IQR or x > Q3 + 1.5 × IQR
Scaled MADmedian(|x − median(x)|) × 1.4826
Skew & kurtosisStandardized third and fourth moments; kurtosis is excess

The browser app provides exploratory diagnostics, not inferential conclusions. For normality tests, grouped profiles, and reproducible Quarto reports, use the DataSum R package.

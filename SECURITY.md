# Security Policy

DataSum is an R package for local statistical diagnostics and report generation. It is not intended to collect credentials or operate as a network service by default.

## Supported versions

Security fixes are considered for the current GitHub development version and the latest CRAN release.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Email the maintainer listed in `DESCRIPTION` with:

- a short description of the issue
- steps to reproduce it
- affected versions, if known
- any suggested mitigation

Current maintainer email: uzairkhan11w@gmail.com

## Scope

Security reports may include issues such as unsafe file handling, report rendering risks, Shiny app upload handling, or accidental exposure of local paths/data.

General statistical questions, feature requests, and ordinary bugs should be opened as GitHub Issues instead.
